RiverGrip 2D

Sobrevoe o rio, resgate sobreviventes e mantenha seu avião em segurança.

Controles

  • No celular, segure os controles para mover e atirar; toque em PULAR para saltar
  • Nas pontes, use J ou PULAR para saltar sem perder vida, ou acerte 3 tiros para destruí-las
  • ← → ou A D — esquerda / direita
  • ↑ / W — frente
  • ↓ / S — trás
  • Passe sobre o FUEL para recuperar 10% do tanque
  • Pegue os corações para ganhar vidas (máximo: 6)
  • Espaço — atirar
  • Enter — iniciar / reiniciar

    GUIA RÁPIDO

    Como jogar

    • No celular, segure o direcional para mover e ATIRAR para disparar.
    • Desvie dos inimigos e mantenha o avião dentro do rio.
    • Pegue sobreviventes, combustível e corações para pontuar e ganhar vidas.
    • Nas pontes, toque em PULAR ou pressione J para saltar sem perder vida; ou acerte 3 tiros para destruí-las.
    • No teclado: setas ou WASD para mover, Espaço para atirar, J para pular e P ou Esc para pausar.
